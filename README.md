## About the Project

This is a CSS-focused project. The goal was to design and style a complete, professional portfolio from scratch and practise layout, typography, colour and responsive design. The HTML provides the page structure, and the CSS handles the design.

## CSS Concepts Practised

- **Flexbox** for the navbar, hero section, buttons and footer
- **CSS Grid** for the about, skills, projects, journey and contact layouts
- **Media queries** for tablet and mobile layouts
- **Positioning** (relative and absolute) for the timeline dots and floating hero label
- **Transitions and hover effects** on cards, buttons and links
- **Typography** with Google Fonts (Poppins and Inter)
- **A consistent colour palette** of navy, lavender and off-white across all sections

## Features

- Responsive navigation bar
- Hero section with profile picture
- About Me section
- Education timeline
- Technical skills section
- Featured projects section with links to GitHub
- Contact section
- Professional footer
- Fully responsive layout for desktop, tablet and mobile

## Technologies Used

| Technology | Purpose |
|------------|---------|
| CSS3 | Styling, layout, colours, typography and animations |
| Flexbox | One-dimensional layouts and alignment |
| CSS Grid | Two-dimensional section and card layouts |
| Media Queries | Responsiveness across screen sizes |
| HTML5 | Page structure and semantic markup |

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/muqaddas147/muqaddas-personal-portfolio.git
   ```
2. Open the project folder:
   ```bash
   cd muqaddas-personal-portfolio
   ```
3. Open `index.html` in your browser.

No installation or build tools are required.
